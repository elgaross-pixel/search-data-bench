# DataForSEO — Source Pack

**Checked:** 2026-09-23
**Evidence grade:** OFFICIAL DOCUMENTED unless explicitly stated otherwise.

## Verified official capabilities

- SERP API supports major search engines and location/language parameters; Google organic endpoints support live results and device selection.
- Keywords Data API documents Google/Bing keyword-data endpoints including search volume and keyword discovery.
- AI Optimization API documents LLM Responses, LLM Scraper, AI Keyword Data and LLM Mentions.
- AI Keyword Data documents AI-search-volume estimates and trends.
- Google AI Mode SERP endpoints are documented.
- Sandbox is available for testing but returns test/sandbox data and is not treated as live quality evidence.
- AI-optimized response format is documented for Live and Task GET endpoints.
