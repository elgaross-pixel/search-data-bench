# Search Data Benchmark #1 — Methodology Draft

Search Data Benchmark #1 (SDB-B01) is designed to compare DataForSEO, SE Ranking API and Mangools API without converting unlike proprietary metrics into a fake common score.

The protocol was frozen before production execution. It fixes United States / English / Desktop conditions, 20 keyword-data tasks and six organic SERP deep dives. Returned data will be preserved as returned; missing fields stay missing and blocked/limited calls remain part of the evidence.

## What will be measured

For comparable tasks: response state, returned-row coverage, missing-field rate, top-10 URL/domain overlap, rank disagreement for shared URLs, search-volume disagreement, runner latency and observable request cost.

Provider-specific difficulty or authority metrics will be shown with their own labels and will not be averaged across providers.

## Evidence grades

Every material observation receives one of: VERIFIED HANDS-ON, OFFICIAL DOCUMENTED, THIRD-PARTY, NOT TESTED, UNAVAILABLE / LIMIT, or UNKNOWN.

## Current status

The protocol is frozen but the three-provider SDB-B01 workload has not been executed. This page therefore describes methodology only and contains no benchmark winner or results.
