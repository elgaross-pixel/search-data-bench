**State:** SOURCE DRAFT / NOT FOR PUBLICATION AS HANDS-ON BENCHMARK
**Evidence date:** 2026-09-23

## What we can verify now

DataForSEO exposes a broad API surface for search data. Its official documentation covers organic SERPs, keyword data and a separate AI Optimization family. The AI family includes LLM response generation/scraping, AI keyword data and LLM mention data. Google AI Mode SERP endpoints are also documented.

That breadth makes DataForSEO relevant to Search Data Bench because the same provider spans conventional search data and newer AI-search datasets. This is a capability observation, not a quality verdict.

## What we have not tested yet

Search Data Bench has not completed the frozen SDB-B01 live workload against DataForSEO. We therefore do not claim measured latency, completeness, accuracy, cost for our workload, or superiority to SE Ranking, Mangools or SerpApi.

The prepared sandbox path is intentionally excluded from quality claims because sandbox output is not live production evidence.
